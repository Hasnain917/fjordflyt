# Fjordflyt website

Complete static Home and Booking pages, including images, logo, hero video,
animated footer clock, and neon section background animations.

## Preview
Open index.html in your browser, or run:

    python -m http.server 8080

Then open http://localhost:8080

## Hosting
Upload the contents of this folder to your hosting web root (public_html).
No build command or dependencies are needed. Keep the assets folder intact.
For Vercel, import the repository as Other, with no build command and the
project root as the output directory.

## GitHub
Extract this ZIP, open this folder in Antigravity, and ask it to push all
files to https://github.com/Hasnain917/fjordflyt on main.

## Booking
Booking selection, quantity counters and pricing run in the browser.
Real reservations and payments require a backend/payment integration.

## Animation assets
Hero laser and footer clock reference media originate from https://huly.io/.
